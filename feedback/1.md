1. Player screen should be left-right not top-bottom. The initiative cards should be in the left half and the active creature's name, picture, and info box should be on the right half. In addition, the active creature should always be at the top of initiative tracker on the left: it should look like:

If creature 1 has already acted:

___"Round 1" header___
[ Creature 2 card ] - active
[ Creature 3 card ]
___"Round 2" header___
[ Creature 1 card ]

Think of it as a queue: the active creature is at the end of the queue, and after its turn, it pops out and goes to the back of the line.

2. Creatures always show as healthy in the player screen even if wounded on the DM's screen.

3. I'm a heavy vim user and would prefer a modal approach to hotkeys rather than key chords. For instance adding a new creature on the Creature screen can just be `n`, same for notes, etc.; `/` to search within the current category, `shift+space` to open a universal search like Ctrl+P.

4. Would it be possible to add vim like navigation to the embedded text editor? Do any premade embedded editors support a vim mode?

5. Fields that involve selecting from a potentially large list of options, like "parent location", should be an autocompleting text field rather than a dropdown selector.

6. Creature statblocks should be formatted like the statblocks native to the system. For instance PF2e creatures should be formatted like the statblocks on 2e.aonprd.com. Editing should probably not involve a big vertical stack of text fields. In fact, for PF2e you can do a creature builder utility based on https://2e.aonprd.com/Rules.aspx?ID=2874. Essentially the user specifies a creature level, and then can select high/low/etc. for each field and autocalculate the number. See for instance how this tool works: https://monster.pf2.tools/
